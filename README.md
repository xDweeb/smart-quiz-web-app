# Smart Quiz Web App

This is a learning project for the Web Development module.

We will build it step by step during the lessons.

## What we already learned

- HTML structure
- CSS formatting
- Classes and styling
- Basic database concepts
- SQL basics
- SQLite with Python

## Project idea

Smart Quiz Web App is a simple quiz website where questions and answers are stored in a database.

## Files

- index.html: the web page
- style.css: the design of the page
- main.py: Python code for working with the database
- data/quiz.db: SQLite database file
